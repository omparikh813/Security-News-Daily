Malicious npm Packages Target Developers in New Supply Chain Attack

Cybersecurity researchers have found 14 malicious npm packages that impersonate popular logging libraries in a new software supply chain attack aimed at developers.

The packages run a post-install script that collects cloud credentials, SSH keys, and CI tokens from the developer's machine and sends them to a remote server.

The packages have been removed from the registry. Developers who installed them should rotate all tokens and keys stored on affected machines and audit their lockfiles.
